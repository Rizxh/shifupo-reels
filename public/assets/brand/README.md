# Logo resmi

| File | Isi |
|---|---|
| `logo-shifupo-red.png` | Logo resmi "SHIFU PO, Business, Love & Life", PNG transparan 1500×476, dari shifupofengshui.com |

Cara memakai: isi `"logo": "assets/brand/logo-shifupo-red.png"` di `brand` pada JSON episode. CTA format `popout` lalu menampilkan logo ini sebagai pengganti nama yang diketik (lihat SP03). Format `story` belum memakainya.

Kalau ada versi lain (emas, putih, SVG), taruh di folder ini dan catat di tabel di atas. Panduan: `docs/guides/06-PENEMPATAN-ASET.md`.
